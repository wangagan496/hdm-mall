# 协议草案数据依据

| 正文事项 | 实际代码依据 | 已确认与待确认边界 |
| --- | --- | --- |
| 账号、密码、登录会话 | `server/src/schema.sql` users/sessions；`server/src/accounts.ts` register/login/authenticate/logout | 随机盐+scrypt保存密码摘要；随机登录凭据在服务端保存摘要，有效期24小时；本机登录状态仍需保存凭据，不能称全部端均只存摘要 |
| 昵称、头像、生日、性别、职业、手机号、地区 | accounts.ts profile/updateProfile；`shoph5-vue3/src/stores/profile.ts` | 服务端profile JSON与白名单更新字段；不宣称强制收集全部字段 |
| 资料草稿 | profile.ts retainDraft/restoreDraft/flushProfile | 本机localStorage按userId隔离，只存白名单资料、未上传头像base64与expiresAt，不存token；7日后下次读取删除，成功保存删除，不是后台定时删除 |
| 地址与编辑回执 | schema.sql addresses、orders地址快照；`server/src/migrations/006-address-autosave.sql` | 地址保存会话与删除墓碑；删除常用地址不删除订单快照 |
| 亲友、购物车、订单、评价 | schema.sql relations/carts/orders/order_items/evaluations | 记录双方关系、勾选数量、金额、履约和评价；数据归属与参与者权限见《交易规则与权限矩阵》 |
| 付款、退款、通知与人工处理 | `server/src/migrations/007-payments.sql` | 付款账号、状态、金额、退款和处理回执；当前模拟渠道，未验收真实资金 |
| 取消与回执 | `server/src/migrations/008-order-cancellation.sql` | 取消申请、处理状态与动作回执；自动核对为查询，原有确认与幂等机制不取消 |
| 售后及照片 | `server/src/migrations/012-after-sales.sql` after_sales/items/images/actions、merchant_settings | 售后说明、数量、照片哈希、寄回物流、退货地址、拒绝原因及退款；仅实际参与角色按权限读取 |
| 系统权限 | `mixed-development-h5/products/phone/src/main/module.json5` | INTERNET、GET_NETWORK_INFO、MICROPHONE、VIBRATE；删除未使用的 KEEP_BACKGROUND_RUNNING，不增加相册或相机权限 |
| 语音搜索 | `features/home/src/main/ets/presentation/components/HDMAudioSearch.ets`；`commons/device/src/main/ets/SpeechToTextManager.ets`（相对mixed-development-h5） | 使用前请求麦克风，系统识别createEngine online:1；商城无音频表不代表系统不联网处理，正文保留系统服务处理与保存规则待确认 |
| 选图与拍照 | 同上device目录 PhotoPlugin.ets、CameraPlugin.ets | PhotoViewPicker只取选择的URI并读取；cameraPicker系统拍照，不据此声称读取全相册 |
| 本地收藏、足迹、待确认动作 | commons/storage AccountScope、LocalGoodsStore、EvaluationDraft、CancelActions等 | 按账号隔离；未实现统一自动清理，不承诺退出全部删除 |
