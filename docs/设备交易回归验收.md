## 已修复问题

原生商家点击“确认发货”后失败，设备请求的 Content-Type 为 application/x-www-form-urlencoded，Fastify 返回 415 与 FST_ERR_CTP_INVALID_MEDIA_TYPE，订单仍为待发货；鸿蒙 Axios 对无正文 POST/PUT 默认设置表单类型，同一调用方式还用于亲友收货和退出登录。

RequestAxios.ets 的 post、postSilent、put、putSilent 在没有业务参数时发送空 JSON 对象，postForSession 同样发送空对象；有参数的正文、指定会话凭证及写操作不自动重发的行为保留。修复前专项测试失败，修复后通过，重新构建安装后的原生商家发货探针也已通过，订单变为待收货。

FamilyView.ets 在浅色卡片上明确设置文字和输入框颜色，修复系统深色模式下白字难以辨认的问题；亲友关系与订单列表使用包含最新字段的行标识，使普通接口对象更新后重建变化的行，避免沿用旧状态和按钮。列表调整依据源码与既有库存页经验，不声称修改前已在本页面复现状态卡住。
