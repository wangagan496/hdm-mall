## 可复跑检查

本轮自动检查共 78 项：58 项客户端逻辑、桥接及页面脚本隔离检查，加 20 项服务端测试。平台依赖替换测试验证业务逻辑，不代替鸿蒙系统服务或真实设备回调。

```powershell
pwsh -File D:\hdm-mall\scripts\verify-optimization.ps1
```

服务端目录运行 `npm run check`、`npm test`；H5 目录运行 `pnpm run lint`，其中 oxlint 和 ESLint 均通过。`verify-optimization-build.ps1` 执行移动端契约检查、vue-tsc、Vite 构建、原生 assembleApp 和签名，再由 `verify-package-web.ps1` 对安装包内网页与 rawfile 的 SHA256 做强制一致性检查。普通网页构建及旧同步入口另行验证，不把仅检查静态目录等同于包内检查。

```powershell
pwsh -File D:\hdm-mall\scripts\verify-optimization-build.ps1
pwsh -File D:\hdm-mall\scripts\verify-package-web.ps1
pwsh -File D:\hdm-mall\scripts\device-optimization-smoke.ps1
```

模拟器为 API 24；冒烟脚本使用临时内存数据库，只检查公开分类、搜索排序和商品详情，不向用户原数据库写订单或资料；结束时恢复原连接并停止夹具服务。截图位于 `_device_acceptance/optimization/detail.png`。本轮两次定位修正了验收脚本的 HDC 移除命令和控件文字，最终完整步骤通过；这些脚本修正不冒充业务缺陷。

## 未纳入与设备边界

退款、人工客服、改址补运费、商家结算、自动收货、多品牌筛选、收藏足迹服务端同步属于新增功能；代收规则变更和商家页面迁移仍是候选，本轮均未实施。头像上传迁原生、原生乐观预览属于待评估方案，本轮保持上传位置及“服务器确认后再正式同步”的规则。

真实设备尚需验收：相机/相册取消及权限回调、语音最终结果与录音资源释放、桌面卡片实际失败码和重试、锁屏/改时间/回到前台、H5 与原生生日及关闭确认交互。模拟器公开浏览通过不覆盖这些场景；没有测量启动速度、识别耗时、缓存速度收益或真实支付效果。当前 SDK 仍为 API 24，未升级到 API 26。

## 本次修复可复用的检查

保存链跨多个接口时，以每个服务器确认点更新已保存基准，不能读取晚到回应时的实时输入；已确认头像不能因其他资料失败被回滚成旧值。取消写请求回应丢失时先查询，不以网络异常推断最终状态。发布网页时检查实际安装包内所有 rawfile/index.html；本轮该检查找到并去掉了一份普通源码构建检查发现不了的旧副本。这些步骤已在对应测试中验证，复用时仍应核对接口是否保持相同确认与幂等规则。
