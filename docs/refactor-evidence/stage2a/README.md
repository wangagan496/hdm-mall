## 字段、确认与冻结

契约目录 `contract-kit/v1/promises/` 维护规范 `promises-20261118-1`。九个通用字段为退换期限、发货时效、包邮或运费承担、保修期、赠品、材质成分、产地、规格参数、保质期或有效期。另有服饰洗涤护理、箱包里料、鞋靴鞋底材质。期限采用原文数值和目录所列单位，文字字段保留整句且没有独立单位。服务端逐字验证整句、定位、条件和单位，拒收有歧义、不合规则或含模型指令的候选。字段可为已说明、未知或不适用。结构化承诺由抽取生成，商家对已说明的每条分别决定确认或不采纳。

店主申请发布时，服务端发出五分钟有效的一次性随机凭据，库内仅保存 SHA256。凭据绑定店主账号、登录会话、当时身份及身份版本、商品版本、草稿摘要和逐项决策。发布在事务内重验并消费凭据，同时写入发布回执。相同账号、商品和 `requestKey` 可读取原回执并得到原发布结果。商品修改使旧草稿失效，仍保留先前发布内容。

下单事务将 SKU 对应商品的发布快照写入订单项，保存规范版本、商品版本、承诺原文与出处、值、单位、条件和回执。买家身份的订单本人确认收货后可核对有明确原文的条目。售后提交携带商品规格和字段引用，服务端从订单冻结数据核验并解析引用。已有订单缺乏已发布快照时显示「下单时无已发布承诺」。

## 调用预算

默认每个数据库累计 50,000 token，单件商品每小时最多三次，模型超时默认 20 秒。调用前按序列化请求的 UTF-8 字节数加输出上限 1,024 和封装余量 256 预留。已报告的用量替换预留值，未返回用量的尝试保留预留。调用记录关联商品、版本、操作者、模型、提示词及目录版本，并保存状态、时间和 token，不存完整输入或密钥。

智谱官方错误码 `1113`、`1308`–`1310`、`1314`、`1316`–`1321` 分别涵盖欠费、调用或消费额度触顶、资源包到期等情况，任一命中均停止该数据库的后续新调用。通用 HTTP 429 仍按临时失败处理。依据 [智谱错误码](https://docs.bigmodel.cn/cn/api/api-code.md)。
