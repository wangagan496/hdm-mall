# 收货后评价设备验收

现有 Pura 90 API24，目标 127.0.0.1:5555。已根据监听进程核对实例。两轮安装同一调试签名包，使用普通登录页面和本人收货入口，付款及物流使用隔离测试服务。夹具通过现有服务准备冻结了承诺的待收货订单，之后的收货、售后申请、评价、商品详情、改评、回复均从应用界面操作。

| 页面 | 浅色截图 | 深色截图 | 逐张核对内容 |
| --- | --- | --- | --- |
| 买家评价 | [评分](light/01-ratings.jpg) | [评分](dark/01-ratings.jpg) | 商品三颗星、物流四颗星、售后五颗星同时可见，版型原文与“符合”选择一致 |
| 商品详情 | [商品评价](light/02-goods.jpg) | [商品评价](dark/02-goods.jpg) | 标准款，三项均值 3.0、4.0、5.0，中评 1 条，买家确认收货依据、冻结版本和版型原文可读 |
| 买家改评 | [改评](light/03-edit.jpg) | [改评](dark/03-edit.jpg) | 已发布原文与新输入同时可见，显示 15 天政策及提交改评按钮 |

每轮发布后以公开商品接口读回商家回复，买家详情的修订号为 2，历史保留第一版正文。截图均为 720 像素宽 JPEG，各自大小和完整 SHA256 记录在 [screenshots.json](screenshots.json)。两轮都恢复原深色主题、清理测试端口映射并释放 3103，相册从开始到结束均为 1 项。现场记录见 [浅色清理结果](light/cleanup.json) 和 [深色清理结果](dark/cleanup.json)。
