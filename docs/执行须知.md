# 惠多美执行须知

首版：2026-11-14，D包本机验证所得；只记录已实际执行的做法，不代表真实支付、真实物流或生产环境验收完成。

## 设备与隔离

- 惠多美只复用现有 `Pura 90 API24`；本次已核对 `127.0.0.1:5555` 的监听进程为该实例的 `Emulator.exe`。启动、安装前仍须重新核对名称与设备对应，不能默认取第一台在线设备。
- 不重启模拟器、不清数据、不重置、不新建或克隆、不执行 `hdc kill-server`，不操作5557或5559；卡住且现有实例无法复用时保留证据并报告阻碍。
- 设备交易回归使用3103上的独立内存服务，设备3000临时反向映射至3103；`hdc fport ls`会列出其他设备，必须只筛选目标5555。逐轮保留原映射，结束后恢复并核对3103空闲、夹具进程退出和临时上传目录删除。
- `hdc file recv`的本地目标使用原生Windows路径；曾因使用正斜线目标路径接收失败，不应误判为设备失联，也不应因此重启模拟器。

## 构建与测试

- 服务端在 `server` 内执行 `npm run check`、`npm test`；随机测试可用当前本机Node支持的 `node --test --test-randomize --test-random-seed=271113 test/*.test.ts`，记录实际seed与零跳过结果。
- 客户端隔离测试在仓库根执行 `node --test scripts/tests/*.test.mjs`；随机顺序同样显式记录seed。发货接口现需承运商和运单，旧测试必须填写新表单后提交，不能通过放宽生产校验恢复旧测试。
- 本工程没有项目内 `hvigorw.bat`；从 `DevEco Studio` 环境变量定位安装目录下的 `tools/hvigor/bin/hvigorw.bat`，在 `mixed-development-h5` 内执行 `test --mode module`。记录真实用例数；命令成功但零用例不代表行为覆盖。
- 签名构建使用 `pwsh -File scripts/verify-optimization-build.ps1 -SkipH5`；它同时核对包内H5与源构建产物。完整构建日志默认写入系统临时目录 `hdm-optimization-build.log`，交付前应复制进本包证据目录。
- 同一轮正式设备验收使用冻结包与SHA256；`device-trade-regression.ps1`支持 `-PinnedPackage` 和 `-ExpectedPackageSha256`，每次安装前重新计算。改了原生源码必须重新构建，先前轮次不能算作新包正式结果。

## 探针与故障记录

- 商家“确认发货”现在只打开表单；填写 `shipping-tracking-number` 后操作 `shipping-submit` 才发货；拒绝取消并发货也必须填写运单。承运商下拉支持“其他”。
- `-LogisticsProbe`只走原生发货、正常轨迹、签收提示、确认收货及三个独立时间；物流乱序、重复通知等外部系统异常由服务端测试覆盖，不另放进正式设备探针；`-ReconcileProbe`覆盖商家入口、按日差异、重复对账、处理原因和审计。正式验收次数以各包 `final-verification.json` 为准。
- UI定位先读设备布局与控件ID；输入后复读控件文字，仅在实际键盘出现时返回关闭键盘。截图保留原图，视觉检查与接口/数据库断言分别记证。
- 已复现并修复：发货时多次读取系统时钟会让订单和运单相差毫秒，备份一致性校验失败；订单、运单及发货审计使用同一时间快照。
- 已复现并修复：离页或换账号时物流刷新锁未清理会留下禁用按钮；清理当前上下文，并拒绝旧响应覆盖新页面。
- 对账日期输入的同值回调不能递增查询版本；加载期间忽略日期变化，避免当前请求结果被作废后遗留禁用状态，已有红绿隔离测试。
- 使用同一模拟支付对象重开数据库时须重新绑定数据库和时钟，否则模拟账单会写入已关闭连接。
- 对账处理时间与对应审计时间也须共用一次时钟读取；已用每次推进1毫秒的时钟复现正常备份被拒，修复后正常备份通过且原因不符仍被拒。
- 新增物流卡片改变订单详情的滚动位置；售后提交寄回后，“等待商家验收”可能位于当前画面上方，探针应先向上找提示再截图，不把屏幕外文字误报为业务失败。
- 用户暂停或退出后，未产生完整结果和清理记录的目录按中断保留，不补写成功；恢复前重新核对进程、设备及映射，新的设备启动必须有当前明确授权，不能沿用此前的一次授权。
- 保留红测和失败设备目录，标明原因且不计正式轮次；每轮须有 `result.json`、`cleanup.json`，不能用日志最后一句成功代替完整证据。
