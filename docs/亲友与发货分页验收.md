# 亲友与发货分页验收

日期：2026-10-28。范围：亲友中心的订单查询与商家待发货列表。

## 实现

新增 GET /member/family-orders/page 和 GET /merchant/orders/page，返回 items、counts、pages、page、pageSize；先用原有权限与状态条件计数，再在数据库中分页，只查询当前页订单的明细。亲友按下单时间降序、商家按下单时间升序，同一时间以订单编号固定次序。旧数组接口保留兼容现有调用方，新版原生亲友中心使用分页接口，每页 10 条。

FamilyView.ets 为亲友和商家列表分别显示页码、上一页和下一页；翻页失败保留当前页，重试成功才替换；发货等操作导致末页消失时重新查询当前最后一页。关系、亲友订单和商家订单的同一次加载使用发起时的会话；新查询、账号切换或离页使旧结果失效，等待期间不借用新账号继续查询。

本次权限审查发现 present() 原来仅凭商家角色返回完整地址，即使商家从亲友入口查看参与订单也会获得地址；已改为只有下单人或明确的商家发货查询上下文返回地址。普通亲友及以亲友身份参与订单的商家均不获得地址，商家发货入口仍可读取履约信息。
